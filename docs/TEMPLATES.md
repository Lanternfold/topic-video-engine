The intended idea inbox accepts arbitrary topics and rough creative direction. These are initial topic families, not a closed menu:

- Tech
- Cricket

The planner may recommend a format, but must not silently commit the idea to production. The user approves the creative brief first.

## Template graduation checklist

A concept can be called **implemented** only when all relevant items are true:

- [ ] Distinct narrative grammar and scene roles documented
- [ ] Visual system, typography, palette, and focal-point rules documented
- [ ] Motion and transition behavior implemented, not only stored as metadata
- [ ] Audio and narration expectations defined
- [ ] Caption timing and safe areas validated at phone size
- [ ] Evidence and source requirements documented for factual formats
- [ ] Representative sample spec exists
- [ ] Automated tests and pre-flight audit cover its requirements
- [ ] A rendered example has been reviewed and its known limitations recorded

Use **concept**, **in progress**, **implemented**, and **validated** precisely. Do not equate a JSON sample with a finished template.
